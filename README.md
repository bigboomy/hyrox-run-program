# HYROX Running Program

14-week HYROX running program. Athletes enter a 6-minute test distance and get personalised training paces (Aerobic, Threshold, VO2max) for every session, with tick-off progress and a printable A4 program.

**Live:** https://bigboomy.github.io/hyrox-run-program/

## Files
- `index.html` – the whole app. Program sessions are in the `PROGRAM` block at the top of the script.
- `apps-script.gs` – Google Apps Script that records name, email and test distance to a Google Sheet (same email + same distance is recorded once).

## Credits
Pace calculations use the Running Fatigue Factor method by aerobiccapacity.com.
